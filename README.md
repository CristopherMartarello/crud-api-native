# ProdutoCRUD - React Native

Este é um aplicativo simples de **cadastro e gerenciamento de produtos** desenvolvido com **React Native**, utilizando requisições HTTP com `axios` e elementos nativos da interface.

## ✨ Funcionalidades

- ✅ Cadastro de novos produtos com múltiplos campos:
  - Nome (texto)
  - Categoria (seleção via Picker)
  - Tipo (RadioButton)
  - Disponível (Switch)
  - Tags opcionais (Checkbox)
- 🖊️ Edição de produtos existentes
- ❌ Confirmação antes da exclusão
- ⚠️ Validação dos campos obrigatórios com Alert

## 🧪 Tecnologias utilizadas

- [React Native](https://reactnative.dev/)
- [Axios](https://axios-http.com/)
- [@react-native-picker/picker](https://github.com/react-native-picker/picker)
